# 인생 키우기 — 기획

태어나서 죽을 때까지를 한 판에 담는 키우기. 잘못 고르면 일찍 죽고, 죽으면
카드를 받아 다시 태어난다.

## 왜 이 소재인가

키우기가 터지는 건 **구체적**이어서다. 수험생 키우기는 모두가 아는 고통 하나를
정확히 찌른다. 그런데 그 개발사(Basakansoft)는 지금 인생을 **한 칸씩 쪼개
시리즈로** 팔고 있다 — 수험생 → 취준생. 좁은 소재를 하나 고르면 그 시리즈와
정면으로 붙는다.

**비어 있는 건 통째로 하는 쪽이다.** 군대·대학·내 집 마련은 경쟁 소재가 아니라
우리 챕터 이름이 된다. 차별화가 소재가 아니라 구조에 있다.

## 세 가지를 동시에 노린다

| 노리는 것 | 담당 |
|---|---|
| 집착 | 늦게 실패하면 처음부터. 인생은 원래 그렇다 |
| 바이럴 | 결과 화면 한 장. **망한 엔딩이 더 잘 돈다** |
| 재방문 | 환생 카드 + 도감 |

정서는 **분노 반 공감 반**. 분노는 구조에서 온다 — 집값, 사수, 면접 탈락,
학원비. 공감은 사람에서 온다 — 친구, 야식, 부모님 전화, 퇴근길.
유년기는 따뜻하고 뒤로 갈수록 현실이라, 정서 곡선이 저절로 배치된다.

## 한 판의 모양

### 시작 — 집안 뽑기

**태어나는 순간 집안이 랜덤이다.** 이게 첫 화면이고 분노 담당이다.
시작 스탯과 시작 자원이 다르고, **리롤은 환생 카드로만** 가능하다.

### 챕터

챕터마다 일차가 새로 돈다. 실제 날짜로 세지 않는다 — 0세부터 80세면 2만 일이다.

| 챕터 | 나이 | 하는 일 |
|---|---|---|
| 유년기 | 0~7 | 기질이 정해진다. 여기서는 안 죽는다 |
| 초등 | 8~13 | 갈래의 씨앗 |
| 중고등 | 14~19 | 갈래가 크게 갈린다 |
| 진로 | 20~23 | 대학 / 군대 / 취업 / 백수 |
| 청년 | 24~34 | 직장인 / 프리랜서 / 공시생 / 자영업 |
| 중년 | 35~59 | 안정 / 이직루프 / 파산 / 성공 |
| 노후 | 60~ | 엔딩 분기 |

### 갈래를 터뜨리지 않는다

선택마다 가지를 치면 2의 n제곱이 된다. 글을 아무리 뽑아도 못 채운다.

**갈래를 몇 개로 고정하고 챕터마다 갈아탄다.** 어느 갈래로 갈지는 스탯과 기질이
정한다. 손으로 가지를 그리지 않는다. 그러면 콘텐츠가 `챕터 × 갈래`로 끝난다 —
7 × 3~4 = 스물몇 덩이. 지수가 아니라 곱셈이다.

**갈래는 다시 합류한다.** 조폭 → 교도소 → 출소 → 취업 갈래로. 이게 없으면
나쁜 갈래는 콘텐츠가 금방 떨어진다.

### 하루

행동 하나를 고르고, 스탯이 움직이고, 가끔 이벤트가 끼어든다.
챕터 끝에는 관문이 있다 — 수능 점수, 면접, 대출 심사.
관문을 못 넘으면 죽지 않고 **아래 갈래로 빠진다.**

## 스탯

넷 + 자원 하나. 각 스탯이 죽는 방식과 하나씩 연결된다.

| | 0이 되면 |
|---|---|
| 머리 | 트랙 이탈 — 아래 갈래로 |
| 체력 | 과로사 |
| 멘탈 | 번아웃 — 은둔 엔딩 |
| 매력 | 고립 — 인맥 이벤트가 막힌다 |
| 돈 (자원) | 파산 |

**기질은 숨은 축이다.** 착함↔거침, 성실↔요령. 유년기 선택이 만들고 갈래를 정한다.
플레이어가 "착하게 키웠는데 날라리가 됐다"를 겪어야 다시 한다.

## 죽음

나이대마다 사인이 다르다. 그게 그대로 결과 화면이 된다.

> 17세 · 오토바이 · 친구 셋과 함께

유년기는 사망 없음. 초등부터 연다.

## 환생 카드

죽거나 엔딩을 보면 카드를 뽑는다. 영구 버프이고 등급이 있다.

- 엄마 찬스 — 시작 돈 +50
- 타고난 체력 — 최대 체력 +20
- 금수저 확률 +5%
- 한 번은 살아남는다

**환생은 무조건 태어날 때부터다.** 도달한 데서 이어 하면 집착이 안 생긴다.
카드가 다음 판을 빠르게 만든다.

가챠·등급·합성·저장은 디펜스에서 쓰던 것을 그대로 옮긴다.

## 도감

엔딩만으로는 수집욕이 약하다. 취준생 키우기가 회사 명함 300장을 모으게 하는 게
이 때문이다.

**인물 도감**을 둔다. 초등학교 짝꿍, 군대 고참, 팀플 빌런, 첫 직장 사수.
챕터마다 다른 인물이 나온다. "엔딩 보려고"보다 **"그 사람 또 만나려고"** 가 세다.

## 만드는 순서

**유년기 + 초등만 먼저.** 갈래 3개까지.

여기까지만 해도 "착하게 키웠는데 날라리가 됐다"가 돌아간다.
재미있으면 나머지 챕터는 같은 틀을 복사하는 일이고,
아니면 스물몇 덩이를 쓰기 전에 안다.

## 아직 안 정한 것

- **한 판 몇 분인가.** 10분이면 챕터당 8일, 25분이면 20일
- **첫 판에 죽는가.** 인생의 절반만 보여 주고 끊는 쪽이 제일 궁금해진다
