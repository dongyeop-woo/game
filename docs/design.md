# 유튜버 키우기 — 기획

채널 하나를 판다. 뭘 올릴지 매일 고르고, 구독자가 붙고, 선을 넘으면 고소가 온다.
채널이 죽으면 남은 것을 들고 부계정을 판다.

## 왜 이 소재인가

키우기는 **숫자가 올라가는 장르**인데 유튜브는 그 숫자가 이미 박혀 있다.
구독자, 조회수, 정산액. 결과 화면이 저절로 나온다 — "구독자 120만" 또는
"고소장이 왔다".

분노는 구조에 널려 있고(알고리즘, 노란 딱지, 저작권, 협찬 사기) 공감도 널려
있다(첫 구독자, 고정 댓글, 같이 시작한 친구). **분노 반 공감 반**이 저절로 된다.

그리고 만드는 사람이 2만 유튜버라 소재가 정확하다. 겪은 사람이 쓴 글과
상상해서 쓴 글은 티가 난다. 시스템은 이쪽에서, **소재는 저쪽에서** 온다.

## 한 판의 모양

### 시작 — 컨셉 뽑기

채널을 팔 때 컨셉이 랜덤이다. 이게 첫 화면이고 분노 담당이다.
잘 터지는 컨셉(이슈·리뷰)이 드물게 나와야 한다.

### 구간

구독자 구간마다 일차가 새로 돈다. 구간 안에 목표를 못 채우면 거기서 끝난다.

| 구간 | 구독자 | 일수 |
|---|---|---|
| 무명 | 0 ~ 1천 | 10 |
| 실버 버튼까지 | 1천 ~ 10만 | 14 |
| (예정) 골드까지 | 10만 ~ 100만 | |
| (예정) 그 뒤 | 100만 ~ | |

### 업로드 주기 — 편집 실력이 정한다

| | 열리는 편집 | 하루 영상 | 완성도 | 체력 |
|---|---|---|---|---|
| 주 1편 | 0 | 0.55 | ×1.45 | ×0.55 |
| 주 3편 | 20 | 1 | ×1 | ×1 |
| 1일 1영상 | 45 | 1.9 | ×0.68 | ×1.9 |

**고르는 게 아니다.** 편집이 10인데 1일 1영상을 고를 수 있으면 말이 안 된다.
편집이 문턱을 넘는 순간 주기가 바뀌고, 손에 든 카드의 이득도 다시 굴린다.
그래서 편집이 성장의 열쇠가 된다. 문턱 값은 임시다.

### 하루

뭘 올릴지 고르면 스탯이 움직인다. 하루에 셋. 가끔 일이 끼어든다.

**올린 영상의 숫자는 다음 날 아침에 온다.** 카드에 박힌 숫자는 예상이고,
아침에 운(0.6~1.5배)이 섞여 실제가 된다. "올리고 자고 일어나서 본다"가
이 직업이라, 하루의 긴장이 여기서 생긴다. 아침엔 제목·조회수·구독자와
**댓글**이 같이 온다.

구독자는 **계산해서** 붙는다. 고정값으로 주면 스탯을 올릴 이유가 없다.

```
예상 = 구간기본 × 영상배수 × 주기(영상수 × 완성도)
       × (1 + 기획/55 + 편집/65) × (1 + 자극×0.015) × 결(맞으면 1.6, 틀리면 0.8)
       × 장비배수 × 한 번짜리 배수
```

스탯과 자극을 **더하기**로 묶었다. 곱하면 후반에 스탯 99 × 자극 80이
수십 배가 돼서 골드가 닷새 만에 끝난다.

### 댓글

아침 결과마다 1~3개 달린다. 결과가 좋으면 칭찬이, 자극도가 높으면 욕이
는다. 댓글 하나가 멘탈 ±1 - 숫자보다 댓글 문장이 먼저 멘탈을 건드려야
"댓글창을 닫았다" 엔딩이 납득된다. 스튜디오 커뮤니티 탭에 쌓인다.

### 알고리즘 — 매주 바뀐다

매주 알고리즘이 **정성 / 물량 / 유행 / 자극 / 소통** 중 하나를 민다. 맞는
결의 영상은 유입이 뛴다 (임시 배수 1.6).

**숫자로는 안 알려 준다.** 두 가지로 알아낸다.
- 카드에 박힌 구독자 수가 유독 큰 걸 보고 눈치챈다
- "쇼츠를 본다" 카드를 쓴다. 틱 하나를 내면 피드에서 본 것을 말해 준다 -
  결 이름이 아니라 "썸네일이 죄다 빨갛다" 처럼

실제로 피드를 보며 감을 잡는 것과 같다. 카드 뽑기와 맞물려서, 이번 주 결에
맞는 카드를 찾으려고 다시 뽑게 된다.

### 수익 창출 — 실제 유튜브 파트너 프로그램대로

1. **조건**: 구독자 1,000 + 지난 90일 시청 4,000시간(또는 조회수 1,000만)
2. 조건을 채우면 알림이 오고, **스튜디오 → 수익**에서 신청한다
3. **사흘 검토** 뒤 승인. 그때부터 조회수 1,000회당 RPM(1,500원)이 쌓인다
4. **매달 21일**, 잔액이 **최소 지급액 10만 원**을 넘으면 들어온다. 안 넘으면
   다음 달로. 노란 딱지면 4분의 1

돈은 실제 원 단위다. 시작 자금 30만 원, 편의점 간식 6천 원, 카메라 120만 원.
**기대보다 적게 나와야 한다** — 그게 이 직업의 분노 담당이다. 300판
무작위에서 정산을 실제로 받은 판은 48%다. 조건 → 사흘 → 21일 → 10만 원이
다 맞아야 해서. 사람이 하면 더 받겠지만 그래도 드물 것이고, 그게 맞다.

### 상점

돈 쓸 데가 없으면 정산이 안 기다려진다. 간식·커피(스탯), 편집 강의,
썸네일 외주·광고 집행(다음 영상 한 편 배수), 조명·마이크·카메라(영구
배수), 좋은 의자(체력 소모 완화), 변호사 상담(자극도 -25, 경고 뒤에만).

### 주간 결산

월요일 아침마다 한 장. 올린 영상·조회수·구독자, 그리고 **지난주 알고리즘이
뭐였는지**를 그제야 알려 준다. 몇 편이나 맞췄는지 보면 쇼츠를 봤어야
했다는 걸 깨닫는다. 캡처 포인트다.

## 스탯

넷 + 자원 둘(구독자·돈). 각 스탯이 죽는 방식과 하나씩 연결된다.

| | 낮으면 |
|---|---|
| 기획 | 노출이 안 된다 |
| 편집 | 이탈률이 높다 |
| 체력 | 0 이면 **번아웃** |
| 멘탈 | 0 이면 **댓글창을 닫는다** |

**숨은 축 둘은 숫자로 안 보여 준다.** 정직↔자극, 성실↔대충.
보이면 최적해를 찾아 버리고, 그러면 "정직하게 하려다 어느새 사이버 렉카"가
안 나온다.

## 선을 넘으면

자극도가 올라가면 **경고를 먼저 준다.** 아무 예고 없이 고소가 오면 억울하기만
하고 다시 안 한다.

1. 40 — 커뮤니티 가이드 경고
2. 60 — 내용증명. 변호사 이름이 적혀 있다
3. 80 — **고소장. 채널 폐쇄**

수위가 높거나 남을 깎아내리는 쪽은 **수익이 확실히 높아야 한다.** 그래야
넘어갈지 말지가 고민이 된다.

## 끝

| 끝 | 조건 |
|---|---|
| 번아웃 / 댓글창을 닫았다 / 장비를 팔았다 | 체력 0 / 멘탈 0 / 빚 1,500 |
| 고소장이 왔다 | 자극 80 (40 경고, 60 내용증명을 먼저 준다) |
| 조용히 접었다 | 구간 일수 안에 목표를 못 채움 |
| 폭로당했다 / 은퇴 영상을 올렸다 | 골드 구간 이벤트 선택 |
| **100만을 넘으면 분기** | 렉카로 남았다(자극 70↑) · 착한 유튜버 · 건물주(잔고 1.5만↑) · 장인(성실+편집 60↑) · 쉬지 못하는 사람(체력 20↓) · 골드 버튼 |

결과 카드는 **공유용**이다. 채널 이름·끝난 이유·구독자·영상·조회수·만난
사람이 한 장에 들어가고, 그림으로 떠서 공유한다. 망한 쪽이 더 잘 돈다.

## 부계정 카드

채널이 끝나면 **둘 중 하나**를 고른다. 9종. 다음 채널이 조금 덜 맨땅이
된다. **컨셉 뽑기를 건드리는 카드가 제일 세다** — 스탯 몇 점은 체감이
없는데 컨셉 한 칸은 채널이 통째로 바뀐다.

## 시작

컨셉이 룰렛처럼 돌다 멈춘다. 별 넷 이상이면 환호, 둘이면 한숨. 그다음
채널 이름을 짓는다 (컨셉별 추천 다섯). 이름이 있어야 결과 카드에 애착이
생긴다.

## 도감

엔딩만으로는 수집욕이 약하다. **사람 도감**을 둔다 — 첫 구독자, 고정 댓글러,
같이 시작한 친구, 협찬 사기꾼. "엔딩 보려고"보다 "그 사람 또 만나려고"가 세다.

## 화면

**유튜브 채널 페이지를 닮게 짰다.** 배너 + 둥근 아바타 + 구독자 수, 얇은 분석
막대, 오늘 올릴 영상이 썸네일 카드로 가로로, 아래에 알림 피드.

처음엔 참고한 키우기 게임 화면(어두운 판 + 2×2 카드 + 틱 점 + ♥)을 그대로
옮겼는데, 그 정도로 같으면 **부정경쟁방지법에 걸릴 수 있다** — 게임 규칙과
화면 조합을 베낀 걸로 판결 난 사례가 있다. 소재가 유튜브니 유튜브를 닮는
쪽이 자연스럽고 안전하다.

## 방

장면 칸의 대부분이 방이다. 구간마다 방이 다르다 - 구독자가 붙을수록 방이
나아지는 게 눈에 보이는 성장이다.

| 구간 | 방 |
|---|---|
| 무명 | 거미줄 낀 자취방 원룸. 컴퓨터 한 대가 방의 전부 |
| 실버 | (예정) |

카드를 누르면 캐릭터가 의자로 가서 앉았다가 돌아온다. 쉬는 카드만 안 앉는다.
